# Review Roles

One writer changes the project. An investigator examines a snapshot before edits;
a reviewer examines the result. The provider of the session writes; the other two
split the remaining roles, and review goes to a provider that did not write the code.
Same-provider fallback is recorded as degraded, not independent verification.
