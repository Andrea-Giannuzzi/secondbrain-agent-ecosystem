AGENT REGISTRY

Profili CAO configurati

—

Un profilo è una configurazione riutilizzabile, non un agente attualmente al lavoro. “Configurato” significa caricabile, senza garantire quota; “In esecuzione” richiede una sessione osservata. I profili storici non sono disponibili al runtime attuale.

Come si collegano ruoli Ruflo, CAO e Librarian

Coordinatore e writer sono l’agente della sessione VS Code o CLI: non richiedono un profilo CAO separato. Il writer è unico.

Investigatore e revisore Ruflo usano i due worker CAO in sola lettura, uno per provider. Cinque profili del Librarian gestiscono semantica, revisione semantica e memoria nella pipeline documentale autonoma.

Profili CAO correnti

Profili storici—

Configurazioni conservate nel registro CAO per tracciabilità, ma non selezionate dal runtime corrente.

Profili CAO integrati e aggiuntivi—

Profili generici registrati in CAO, separati da quelli selezionati per questo ecosistema.

Dove controllare da VS Code e terminale

Antigravity: pannello laterale → Additional Options (…) → MCP Servers. Codex: pannello Codex; nel terminale integrato, codex mcp list.

Per aprire Antigravity dal terminale del progetto: antigravity. Dentro la sessione, /help; per gli MCP, antigravity mcp list. Gli elenchi nativi possono contenere argomenti riservati: non condividerli integralmente.

Skill Codex: ~/.codex/skills e ~/.agents/skills. Skill Antigravity: ~/.gemini/config/skills.json. Hook Antigravity: ~/.gemini/config/hooks.json. Apri i file con File → Apri file in VS Code.

Le configurazioni globali valgono per tutti i progetti. Le cartelle .agents dei progetti e i plugin possono aggiungere personalizzazioni: verificarle nel relativo client. Dopo l’installazione usa Developer: Reload Window e apri una nuova sessione agente.

COVERAGE

Perché alcune Source non hanno un nodo

triage locale · zero quota AI

Una Source resta consultabile anche senza diventare Knowledge. Il Librarian crea nodi solo per contenuti concettuali riutilizzabili e registra il motivo delle esclusioni.

—Tecniche o dati grezziCodice, log, configurazioni ed estrazioni strutturate.
—Testo insufficienteContenuto troppo breve per un concetto affidabile.
—SensibiliDocumenti personali mantenuti solo in locale.
—AmministrativeRicevute, attestati e materiale di servizio.
—In lavorazionePronte o in attesa controllata del Librarian.
—Da verificareCasi senza una motivazione riconosciuta.
